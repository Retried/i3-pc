## Scoped fix

on Linux and macOS for the existing freeze-log CPU counter. Both paths produce
microseconds. If the OS call fails, retain the previous counter value rather
than reading uninitialized data or emitting an unsigned underflow. Include the
platform headers explicitly. Rendering, submission and cache logic are unchanged.

Keep formatting limited to the affected rasterizer. The 44 clang-format paths
match the list in [the previous report](CI_RUN_38766554875.md); they were not
introduced by this fix. REUSE and workflow checks remain enabled.
